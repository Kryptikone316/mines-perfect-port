MINES-PERFECT ART PACK  -  optional backgrounds for the Datafrog SF3500 port
============================================================================

Six background pictures for START > Settings > Background:
  Sunset Valley, Crystal Cave, Moonlit Battlefield, Desert Sunset, Frozen Aurora, Retro Mountains.

INSTALL
  Unzip the pack INTO the port's folder on the SD card, so that the pictures end up in
      roms/ports/minesperfect/backgrounds/
  (copy the "backgrounds" folder from this zip over there). Start the game, open
  START > Settings > Background: the pictures now follow the built-in colours in the gallery.

REMOVE
  Delete the .bg files from roms/ports/minesperfect/backgrounds/. The game goes back to the colours.

YOUR OWN PICTURES
  Any .bmp file in the same folder shows up too (uncompressed 24-bit is safest; 8 and 32 bit also work).
  Best is exactly 640 x 480; any other size is cropped from the middle to 4:3 and scaled to 640 x 480.
