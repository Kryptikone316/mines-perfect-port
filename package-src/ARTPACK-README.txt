MINES-PERFECT ART PACK  -  optional backgrounds for Mines-Perfect on the Datafrog SF3500
=======================================================================================

Six background pictures for the game:
  Sunset Valley, Crystal Cave, Moonlit Battlefield, Desert Sunset, Frozen Aurora, Retro Mountains.

HOW TO INSTALL
  1. Unzip this file on your computer. You get a folder called "backgrounds".
  2. Copy that folder into the game's folder on the SD card, so that the pictures end up in
         roms/ports/minesperfect/backgrounds/
  3. Start Mines-Perfect and open START > Settings > Background. The pictures are in the list,
     after the built-in colours. Browse with Left/Right, A to choose.

HOW TO REMOVE
  Delete the .bg files from roms/ports/minesperfect/backgrounds/. The game goes back to the colours.

YOUR OWN PICTURES
  Any .bmp file in the same folder also shows up in the list. Uncompressed 24-bit works best.
  640 x 480 is ideal; any other size is cropped from the middle to the screen's 4:3 shape.
